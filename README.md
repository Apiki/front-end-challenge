# Blog de Desenvolvimento

Este projeto é um blog criado com React e Vite que consome a API pública do WordPress da Apiki. Ele exibe postagens da categoria **Desenvolvimento**, permitindo que usuários explorem artigos sobre programação, tecnologia e web.

O objetivo é oferecer uma interface moderna, rápida e responsiva para leitura de conteúdos técnicos, ideal para desenvolvedores e entusiastas da área.


## Funcionalidades

- Listagem de posts da categoria "Desenvolvimento" via API WordPress
- Página individual com leitura formatada e tempo estimado de leitura
- Contador de tempo estimado de leitura
- Responsividade para diferentes tamanhos de tela
- Carregamento progressivo com botão “Ver mais artigos”
- Navegação com React Router


## Stack utilizada

**Front-end:** React, Vite, CSS Modules, React Router DOM

**Consumo de API:** WordPress REST API

## Instalação

Para instalar e rodar o projeto localmente, siga os passos abaixo.

### Pré-requisitos

- Node.js instalado (versão recomendada: >= 18)
- npm ou yarn

### Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/PedroMarcusso09/front-end-challenge
```

Entre no diretório do projeto

```bash
  cd front-end-challenge
```

Mude para a branch do desafio

```bash
  git checkout pedro-marcusso
```

Instale as dependências

```bash
  npm install
```

Inicie o servidor

```bash
  npm run dev
```
